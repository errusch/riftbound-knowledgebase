# Riftbound Terminology Glossary

Use this as the canonical terminology guardrail for expert answers.

## Domains

Canonical domains:

- Body
- Calm
- Chaos
- Colorless
- Fury
- Mind
- Order

`Grace` is not a Riftbound domain.

## Stats And Costs

- **Energy**: energy cost to play a card.
- **Power**: rune/domain cost requirement. Do not describe Power as combat
  damage.
- **Might**: unit combat stat. Use Might for combat strength, damage, and
  survivability language.

## Forbidden Or Suspicious Terms

- `Grace`: fake/non-canonical domain.
- `regions`: Legends of Runeterra terminology; Riftbound uses domains.
- `spell mana`: Legends of Runeterra terminology.
- `Nexus`: Legends of Runeterra terminology unless explicitly discussing a
  non-game proper noun.

## Event Lookup Rule

For event answers, open root pipeline event records such as
`events/rq-lille-2026.json` first when available, then compare
`events/canonical/` only as a normalized secondary copy.

## Source Boundary

Never answer from archived or legacy roots unless the user explicitly asks for
historical/archived material.
