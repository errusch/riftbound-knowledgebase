# Riftbound legality

Canonical legality records live here when they come from official Riftbound or
Riot sources.

Use these files for bans, suspensions, and format legality before checking
per-card convenience fields. If this directory conflicts with a card record,
the official legality registry wins and the card record needs repair.

Rules:

- Populate from official Riftbound/Riot sources only.
- Include source URL, retrieved date, effective date, format, and trust tier.
- Do not infer legality for formats the source did not mention.
- If local data is stale, check the live official site and promote verified
  updates back here.
